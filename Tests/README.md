# Tests and Development Files

This folder contains test scripts, diagnostic tools, and development artifacts.

## Categories:

### Test Scripts (.py)
- Various Python test files for different functionality
- Integration tests and unit tests
- Excel processing validation scripts

### Test Excel Files (.xlsx)
- Sample Excel files used for testing
- Output files from various test runs
- Validation spreadsheets

### Diagnostic Tools
- `diagnose_excel_file.py` - Excel file analysis
- `verify_excel.py` - Excel validation utilities

### Development Artifacts
- Backup files from various development stages
- Patch files for specific fixes
- Debug test files

## Usage:

These files are primarily for development and testing purposes. Most end users won't need to interact with these files directly.
