# VBA Macros

This folder contains VBA macro scripts for Excel automation.

## Files:

- **RefreshLegacyView_Hierarchical.bas** - Current working version with hierarchical structure creation
- **RefreshLegacyView_VBA_*.bas** - Various development iterations and versions

## Usage:

1. Open Excel with your workbook
2. Press `Alt + F11` to open VBA editor
3. Go to `File > Import File` and select the desired .bas file
4. Run the macro with `F5` or `Alt + F8`

## Current Status:

The `RefreshLegacyView_Hierarchical.bas` is the most recent version with optimized column mapping and SUM formula creation for building summaries.
